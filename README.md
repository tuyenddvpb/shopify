# Kindhand Co. Shopify Theme

Theme của **Kindhand Co.** (kindhandco.com). Nhánh này chỉ chứa file theme và được nối với store qua Shopify GitHub integration.

- Dựng trên Dawn 16, từ theme VitalRay. Bảng màu Kem `#FBF6EF` / Mận `#3B2A33` / Đất nung `#C4673F`, font Fraunces + Nunito Sans.
- CSS riêng: `assets/vitalray.css` (giữ tên cũ để code cũ chạy được). Logo: `snippets/vr-logo.liquid`.

## Cách sửa theme

- Sửa code trên nhánh này rồi push. Shopify tự cập nhật theme đã nối.
- Sửa trong Theme Editor (Customize) thì Shopify tự commit ngược về nhánh này. Nhớ `git pull` trước khi sửa trên máy.
